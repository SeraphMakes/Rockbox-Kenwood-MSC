# Installation

This package is intended for users who already have Rockbox installed on
an iPod Video 5.5G.

## Files

The firmware directory contains:

    rockbox.zip
    rockbox.ipod

The easiest installation method is to extract rockbox.zip to the root of
the iPod storage, replacing the existing .rockbox files.

## Windows example

1. Put the iPod into Apple Disk Mode.
2. Connect it to the computer.
3. Note its drive letter.
4. Extract rockbox.zip.
5. Copy the contents of the included .rockbox directory into the existing
   .rockbox directory on the iPod.
6. Replace files when prompted.
7. Safely eject the iPod.
8. Boot Rockbox normally.
9. Connect the iPod to the Kenwood USB port.

Back up the iPod before modifying firmware.

Do not repartition or reformat the physical iPod based on the translated
geometry described in TECHNICAL.md.
